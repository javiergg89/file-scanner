# Security policy

File Scanner reads and deletes files in the user's home folder, so bugs that could delete the wrong thing are treated as security issues.

## Reporting a vulnerability

Please report it privately through [GitHub private vulnerability reporting](https://github.com/javiergg89/file-scanner/security/advisories/new), not in a public issue. Include the steps to reproduce and the version (Settings → Apps, or the installer name).

## Supported versions

Only the latest release receives fixes.
